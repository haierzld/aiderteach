# 第28期 | 马斯克600亿买下Cursor，OpenAI转头就“断供”——AI圈的信任清算开始了？

---

> 大家好，我是小智。今天这条新闻，几乎刷屏了整个科技圈：**OpenAI 宣布不再给 Cursor 提供模型了**，断供时间定在 11 月 12 日。
>
> 为什么？因为半个月前，马斯克花了 600 亿美元把 Cursor 的母公司买走了。OpenAI 的解释就四个字：**不信任你**。今天咱就把来龙去脉讲透，再聊聊这件事背后更大的信号。

---

## 一、一条公告，炸了开发者圈

8月28日，OpenAI 在官网发了一则公告，说得很直接：

- 已正式通知 SpaceX：计划终止向编程工具 Cursor 供应模型的合同
- 拟定的断供日期：**2026年11月12日**（合同允许的最长通知期，给开发者留足迁移时间）
- 下一代最强模型 **Astra**，官方渠道**永远不给** Cursor
- 双方合作已经**接近四年**，OpenAI 在公告里还客套了一句“尊重 Cursor 团队和产品”

“但我们无法确信，你的新老板会按我们的服务条款使用技术。”——这句没说出口的话，才是重点。

> 一句话：**不是产品出问题了，是模型方先撤了。**

---

## 二、导火索：马斯克600亿买下Cursor

事情得从半个月前说起。

2026年8月，马斯克旗下的 **SpaceX 以 600 亿美元** 完成了对 Cursor 母公司 Anysphere 的收购。消息一出，全球开发者就炸了锅——那款被无数人当成“日常工具”的编辑器，换东家了。

大家当时就在猜：换了老板，还是原来的味道吗？半个月后，答案来了——**不是产品不行，是模型方先撤了**。

网上有句总结特别传神：**“你老板有前科，我不放心。”**

---

## 三、OpenAI凭啥说“不信任”？两桩旧账

OpenAI 没有指控 Cursor 违约，而是翻出了马斯克的两桩旧账：

### 旧账1：推特数据断供（2022年）

马斯克买下推特后，认为 OpenAI 每年只花约 **200万美元** 就拿走全量推文数据流，太便宜了，直接切断了 OpenAI 对推文数据的访问。

### 旧账2：xAI 偷偷“抄作业”（今年）

马斯克在宣誓证词里亲口承认：**xAI 曾违反 OpenAI 服务条款，用 OpenAI 模型的输出去训练自家 Grok**——圈里管这叫“蒸馏”。

OpenAI 全球政策负责人的原话：**“归根结底是信任问题。”**

> 一句话：**他偷过你家的菜，现在他成了你邻居的新房东，你还能放心把菜园交出去吗？**

---

## 四、更深处：不是恩怨，是生意

表面上是“信任问题”，但懂行的人都知道，这更是一场**商业博弈**：

### 原因1：数据不能流给敌人

Cursor 是全球最大的 AI 编程入口之一，每天涌进海量的**代码和提示词数据**。收购之后，这些数据可能流向马斯克体系——对训练 Grok 来说，这可是“顶级养料”。

### 原因2：xAI 正在抢同一块蛋糕

马斯克的 xAI 正全力做 AI 编程（Grok Build 刚上线），和 Cursor、OpenAI 的 Codex 正面竞争。OpenAI 等于是在给竞争对手**递刀子**。

### 原因3：模型越强，“谁能用”越要管

OpenAI 特别点名 Astra 具备更强的联网能力——**前沿模型的分发权，正在成为比模型本身更稀缺的东西**。

### 原因4：合同里的“分手按钮”

B2B 合同里都有个“控制权变更条款”：合作方一旦被收购，另一方有权选择退出。这次触发条款的不是“换老板”本身，而是**新老板是谁**。

> 一句话：**这一刀，砍的不是旧账，是 Grok 的未来。**

---

## 五、影响多大？Cursor表示“毛毛雨”

听起来很吓人，但 Cursor 联合创始人 Michael Truell 当晚就回应了：

- **OpenAI 模型只占 Cursor 用户 AI 流量的约 5%**
- 主力早已转向 **Claude 和自研模型**，断供伤不到筋骨
- 开发者**自带 OpenAI API key** 的通道不受影响
- OpenAI 还会继续维护 Cursor 的插件扩展

真正让 Cursor 肉痛的，是**未来最强模型 Astra 拿不到了**——“顶级模型”的号召力可是卖点之一。

> 一句话：**断供的伤害有限，但信号很刺眼：中立人设，是供应商给的，不是自己说的。**

---

## 六、这不是第一次：AI圈的“互相断供”大戏

把时间线拉长，你会发现这事早有先例：

- **2025年6月**：传闻 OpenAI 要收购 Windsurf，Anthropic 直接切断了对 Windsurf 的 Claude 供应
- **2025年8月**：Anthropic 撤销了 OpenAI 的 API 权限——理由是 OpenAI 偷偷用 Claude 跑 GPT-5 的内部基准
- **2026年8月**：这次轮到 OpenAI 切断 Cursor

看出来了吗？**谁越强，对“谁能用我”越敏感。** 当模型成为战略武器，供应商和客户之间的关系，就从“互相喂饭”变成了“互相防着”。

---

## 七、小智说两句

这件事最值得琢磨的，不是马斯克和奥特曼的恩怨，而是三个趋势：

1. **模型公司开始“挑客户”**：不是谁给钱就卖给谁，得看你的老板是谁、数据流向哪里
2. **应用公司的“中立”是暂时的**：Cursor 一直标榜“模型无关”，但断供一纸公告，就撕掉了这层包装
3. **开发者得学会“多条腿走路”**：别把命脉押在一家供应商身上，核心流程留好备选方案

对咱们普通用户和开发者，其实就一句提醒：**AI 圈的地震会越来越多，但你的工具箱，永远要有备用钥匙。**
