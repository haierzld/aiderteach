# 第16期 | 实战篇·中：WorkBuddy是怎么"外接全世界"和"身怀绝技"的？（MCP + Skills）

---

> 大家好，我是小智。上一期咱们在 WorkBuddy 里看了 Agent 和 Harness——AI 怎么"自主干活"、又怎么"守规矩"。今天咱们继续看顶层两兄弟：**MCP（万能联络中枢）** 和 **Skills（技能库）**。

> 这两层，普通用户感知最直观的地方就是：**同样一句话，为什么 WorkBuddy 能"真的办成事"，而有些AI只会"说大话"。**

---

## 一、先来一个场景：你想让AI"把PDF里的表格整理进Excel"

这个需求，普通用户经常遇到，正好能一次性带出 MCP 和 Skills。

### 没处理（普通聊天AI）的回复：

> 你可以打开PDF，手动把表格抄到Excel里……（然后没了）

它只会给你"建议"，因为：
- 它**没有打开你电脑文件的通道**（没有 MCP）
- 它**没有处理PDF/Excel的能力**（没有 Skills）

### 有处理（WorkBuddy）的表现：

> 📋 我打算这样做：
> 1. 先找到你电脑里的 PDF 文件
> 2. 用 PDF 技能提取里面的表格数据
> 3. 生成一个新的 Excel 文件并填入数据
> 4. 完成后告诉你文件在哪

然后它真的就干成了，你在文件夹里看到一个崭新的 Excel。

**差别在哪？就差在 MCP 和 Skills 这两层。**

---

## 二、MCP：WorkBuddy 的"万能联络中枢"

咱们第13期讲过，MCP 是 AI 的"联络中枢"，让 AI 能调用外部资源。在 WorkBuddy 里，它的表现是：

### 你能感知到的 MCP：

当你让 WorkBuddy"帮我看看电脑里的文件""帮我搜索一下这个资料""帮我调用云数据库"时，WorkBuddy 不是"凭空想象"，而是**真的通过 MCP 这个"联络中枢"，连到了你电脑的文件系统、搜索服务、外部应用上。**

具体例子：

| 你说的话 | WorkBuddy 背后做的（MCP） |
|---|---|
| "打开桌面上的合同.pdf" | 通过文件访问能力读取你电脑文件 |
| "搜一下上周的会议记录" | 连接本地搜索索引 |
| "把这个数据存到云端" | 通过云服务接口连接数据库 |
| "帮我查今天的天气" | 连接天气服务接口 |

**有处理 vs 没处理的区别：**

- 没处理：AI 说"我没有文件访问权限"，或者瞎编一个文件内容
- 有处理：AI 真的读到了你的文件，并且基于**真实内容**帮你干活

---

## 三、Skills：WorkBuddy 的"技能库"

Skills 就是 AI"会什么手艺"。WorkBuddy 装了不少"技能"，每个技能就是一项专业能力：

### 你能感知到的 Skills：

| 技能 | 是什么 | 你体验到的效果 |
|---|---|---|
| 文档技能 | 会读写 Word、PDF、PPT | "帮我写一份Word报告"它真的生成 |
| 表格技能 | 会处理 Excel、CSV | "把数据做成表格"它真的做出来 |
| 演示技能 | 会做 PPT | "帮我做10页PPT"它真的生成PPT |
| 网页技能 | 会写 HTML | "做个漂亮的网页"它真的写代码 |
| 搜索技能 | 会上网找资料 | "帮我查最新的AI新闻"它真的去搜 |

### 关键点：Skills 是"可复用"的

WorkBuddy 每学会一项技能，下次遇到同类问题**直接调用，不用从头教**。就像管家工具箱里的工具，用顺手了，越干越快。

**有处理 vs 没处理的区别：**

- 没处理：AI 只会输出"生成Excel的步骤说明"，剩下的你自己来
- 有处理：AI 直接调用表格技能，**真的把 Excel 生成给你**

---

## 四、MCP + Skills 配合起来：才是完整体验

真实干活时，MCP 和 Skills 是**一起上阵**的：

> 你说："帮我看看这个PDF里的数据，做个统计表。"
>
> WorkBuddy：
> - **MCP** 负责"取"：通过文件通道打开你的 PDF（外接资源）
> - **Skills** 负责"做"：用 PDF 技能读数据、用表格技能生成统计表（调用技能）
> - 最后把 Excel 放到你指定位置

**这就是顶层两层的分工：**
- **MCP = 进货渠道**（把"外界的料"搬进来）
- **Skills = 加工手艺**（把"搬来的料"做成你要的东西）

---

## 五、为什么普通用户越来越离不开"有这两层"的AI？

### 原因一：省事

以前你要自己：开PDF → 复制数据 → 打开Excel → 粘贴 → 排版 → 保存。
现在：一句话，AI全干完。

### 原因二：靠谱

因为有 MCP 和 Skills，AI 用的是**你电脑里的真实文件**，用的是**专业处理能力**，而不是"凭记忆编"。

### 原因三：门槛低

你不需要会编程、不需要懂技术，只需要会"说人话"交代任务。

---

## 六、给普通用户的三句话

1. **当AI能"打开你电脑里的文件"时，是 MCP 在工作**——它连上了外界资源
2. **当AI能"真的生成Word/Excel/PPT"时，是 Skills 在工作**——它有真手艺
3. **MCP + Skills 齐备，AI 才算"既能拿料、又会做菜"**——这才是完整的"能干活的AI"

## 七、小智说两句

这期咱们看了 WorkBuddy 里的 MCP 和 Skills。你会发现，其实你并不需要懂它们的英文名，你只需要记住两个画面：

- **画面一**：AI 真的打开了你的PDF、你的Excel、你的PPT → 这就是 MCP
- **画面二**：AI 真的生成了一个文件、一份图表、一个网页 → 这就是 Skills

**七层里最"看得见摸得着"的就是这两层——它们把AI从"纸上谈兵"变成了"真刀真枪"。**
