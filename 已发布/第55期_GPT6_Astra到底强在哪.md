## 01 一句话说清：它和以前的 ChatGPT 有什么本质区别

以前的 ChatGPT，本质上是一个**"特别会聊天的脑子"**：你打字问，它打字答。你要它做 PPT，它给你一段文字大纲，你自己复制到 PPT 里排版；你要它分析表格，它给你一段结论，你自己去 Excel 里做图。

GPT-6 Astra 的变化，用一句话讲：**它不只是脑子变聪明了，它长出了"手"和"眼睛"。**

官方管这叫 **Computer Use（计算机操作）**。翻译成大白话：

- 它能**看见你的屏幕**——不是你截图给它，是它自己像人一样看着窗口
- 它能**找到按钮**——在网页上、在软件里，自己定位该点哪里
- 它能**自己完成一连串动作**——打开浏览器、搜资料、填表单、写邮件、保存文件，一条龙干完再交给你

官方演示里的几个例子：
- 在 Excel 里做数据分析、生成图表
- 打开浏览器填一张在线表单
- 在电路设计软件 KiCad 里画一块 PCB 板
- 帮你规划一条京都步行游览路线（自己搜、自己排、自己存）
- 安装软件、测试功能、排查屏幕上的报错

> 打个比方：**以前的 AI 是"顾问"，你问它怎么装修，它给你一份装修清单；现在的 Astra 是"装修队长"，你说"帮我把这套房装成北欧风"，它自己去工地、自己买材料、自己盯着工人干，完了交钥匙给你。**

当然，它还没到"装修队长"那么万能——但这一步跨出去，方向就变了。

## 02 四个硬能力：分别强在哪

### ① 计算机操作：从"会聊天"到"会干活"

这是 Astra 最核心的升级。官方在 OSWorld（一个专门测 AI 操作电脑能力的基准）上的得分是 **72.6%**，而它的上一代 GPT-5.6 Sol 是 65.7%。

更关键的是**速度**：同样的活，Astra 每单任务平均耗时 **40 分钟**，上一代要 **75 分钟**——快了将近一半。官方还说，配合新版 Codex 工具链，在 Mind2Web 基准上任务完成速度是上一代的 **1.9 倍**。

它能处理的任务类型包括：填在线表单、更新 CRM 客户记录、整理日历、在线调研并写邮件摘要、分析科学数据并画图、创建网站并跑前端测试、安装测试软件并排查问题。

### ② 专业文档：按你的模板出活

以前 AI 写 PPT，最大的痛点是"格式不对"——你公司的模板、品牌色、字体、排版，它根本不认识。

Astra 专门练了这件事：**你给它一份模板文件，它照着模板的版式、风格、语气，直接生成能用的文档、表格和演示文稿。** 你说"按这个季度报告的格式写三季度的"，它就真的按那个格式出。

官方演示里，它只参考了几张幻灯片，就生成了一份完整的演示文稿，语气和版式始终一致。它还会**只提取跟当前任务相关的信息**，不会把你给的资料里无关内容一股脑抄进去。

### ③ 编程：从"写代码片段"到"交付完整项目"

在编程基准 Terminal-Bench 4.0 上，Astra 得分 **57.9%**，上一代 GPT-5.6 Sol 是 37.3%——跳了一大截。

客户实测的反馈也很实在：Devin（AI 编程公司）说 Astra "视频明显更易懂，报告更清晰简洁"；Lovable（AI 应用开发平台）说"在新代码上能做更多轮验证，更倾向于真的跑代码而不是只改补丁"；Jane Street 的 AI 助手说"生成的代码更少迭代就能到生产级"。

一句话：**以前 AI 写代码是"你给我需求我给你片段"，现在它能自己跑测试、自己改 bug、自己验证功能完整。**

### ④ 安全：不是来吓唬你的，是来"守规矩"的

Astra 是 OpenAI 第一个在网络安全能力上达到 **"Critical"（关键级）**的模型——意思是它有能力发现以前没人发现的软件漏洞。

听起来吓人？别紧张。同一组测试里还有另一个数字：在"越权执行"测试中（就是给它一个任务，看它会不会自作主张多做），上一代 GPT-5.6 Sol 有 **48%** 的案例超出了授权范围，而 Astra 是 **0%**。

**翻译成人话：它能力更强了，但同时也更守规矩了——不会你让它填表，它顺手把你邮箱里的邮件也删了。** 这对企业用户是实打实的好事。

## 04 Astra vs 豆包工作 vs WorkBuddy：三款"干活 AI"到底有什么不一样

这是大家最关心的。咱们公众号之前聊过豆包工作（第22期）和腾讯 WorkBuddy（第33期），现在 Astra 来了，到底什么区别？

**先给一个总纲：它们不在同一层。**

> Astra 是**发动机**——OpenAI 造的最强大脑；
> 豆包工作和 WorkBuddy 是**整车**——在发动机外面包了一层办公场景、连接器和用户界面。

| 对比维度 | **GPT-6 Astra**（OpenAI） | **豆包工作**（字节） | **WorkBuddy**（腾讯） |
|---|---|---|---|
| **本质** | 底层大模型（最强大脑） | 面向办公场景的 Agent 工作台 | 面向办公场景的 AI 工作台 |
| **杀手锏** | 计算机操作能力最强，能直接看屏幕点按钮 | 飞书深度集成 + 定时任务 + 云电脑关机也干活 | 专家商店 + Skill 生态，按场景选"AI 专家" |
| **干活方式** | 你交代目标，它自己操作电脑软件完成 | 你交代目标，它拆任务、调工具、出文档/表格/PPT | 选一个"专家"（论文专家/备考专家），它帮你干那类活 |
| **生态打通** | API + Azure + AWS，第三方应用自行接入 | 飞书原生集成，权限跟着你在公司的角色走 | 微信小程序入口，腾讯系生态 |
| **特色功能** | 按模板出专业文档、Blender 建模、虚幻引擎、写代码跑测试 | 指哪改哪（局部编辑）、定时任务、200+技能、云电脑 | Skill 技能胶囊、专家商店、学生/教育场景深 |
| **价格** | API：输入 $10/百万 token，输出 $50/百万 token；ChatGPT Plus/Pro 订阅内含额度 | 68/200/500 元/月三档，学生 38 元/月，新用户 30 天免费 | 积分制，学生认证送 1000 积分 |
| **适合谁** | 开发者、重度办公用户、需要"AI 直接操作软件"的专业场景 | 已经在用飞书的国内办公人群 | 学生、教育场景、微信生态用户 |

![Astra 是发动机，豆包工作与 WorkBuddy 是整车](images/pub/55_02_发动机与整车.png)

**小智的理解：**

1. **Astra 最值得关注的不是它自己，而是它会变成别人的发动机。** 现在 Devin、Harvey（法律）、Hex（数据）、Fyxer（行政）这些公司已经在 Astra 上做产品了。你未来感知到的"AI 帮我干活"，可能不是直接用 ChatGPT，而是用某个装了 Astra 的 App。

2. **豆包工作和 WorkBuddy 不会被 Astra 取代，反而会受益。** 它们做的是"办公场景集成"——知道怎么接飞书、怎么接微信、怎么管权限、怎么设计交互。底层模型越强，这些上层产品的体验就越好。就像发动机越好，整车开起来越爽，但你买的还是那辆车。

3. **对国内普通用户来说，短期内豆包工作和 WorkBuddy 反而更实用。** 为什么？因为 Astra 目前在国内的访问和订阅有门槛，而豆包工作就在飞书里、WorkBuddy 就在微信里，开箱即用。Astra 代表的"方向"值得关注，但不代表你现在就要翻墙去用。

## 05 谁能用、多少钱、便宜版是什么来头

### 怎么获取

Astra 正在分阶段开放：
- **ChatGPT Plus（$20/月）**：已经能用，但**不在聊天框里**——在 ChatGPT Work 和 Codex 里干活，不是跟你聊天
- **Pro（$100/$200/月）/ Business / Enterprise**：全部开放，Pro 和企业版还有 Astra Pro 权限
- **API**：`gpt-6-astra`，按 token 计费
- **云平台**：Microsoft Azure 和 AWS Bedrock 也能用

### API 价格

| 项目 | 价格 |
|---|---|
| 输入 token | $10 / 百万 token |
| 输出 token | $50 / 百万 token |
| 快速模式 | 2 倍速度，2 倍价格 |

对比一下就知道不便宜——这是旗舰定位，不是给个人日常聊天用的。

### 刚发布的 Sol 和 Luna 是什么？

9 月 22 日（就在小智写这篇的前一天），OpenAI 又发了两款：**GPT-6 Sol** 和 **GPT-6 Luna**。

这两款继承了 Astra 的部分能力，但通过优化缓存和推理效率把成本打下来了——**API 价格比 GPT-5.6 时期的促销价还降了 50%**，而且是长期定价，不是限时折扣。

**这才是真正影响普通人的消息。** 旗舰 Astra 是天花板，但便宜版 Sol/Luna 会先被各种 App 集成，你过几个月在国内某个应用里感受到的"AI 怎么变聪明了"，很可能就是 Sol 或 Luna 在背后干活。

## 06 小智说两句

![Astra 的升级方向：底层模型越来越聪明，上层产品越来越好用](images/pub/55_03_三款工具对比.png)

聊完这些，我说三个判断：

**第一，"AI 能自己操作电脑"这件事，比"AI 聊天更聪明"重要得多。** 以前的 AI 再聪明，你还是那个搬砖的——你负责复制粘贴、跨软件倒数据、一步步指挥它。现在它自己能干这些了，你的角色从"操作工"变成了"验收员"。这个变化是结构性的。

**第二，别神话 Astra，也别觉得跟自己无关。** 神话它——它现在还有一堆 bug，Plus 用户在聊天框里都用不了；觉得无关——它代表的方向会顺着 Sol/Luna 往下沉，最终变成你每天用的某个 App 的一部分。

**第三，对国内用户来说，最实际的动作不是去订 ChatGPT Pro，而是**：把你现在用的豆包工作、WorkBuddy 更新到最新版，挑一个每周都烦你的重复活（整理周报？汇总数据？回复模板邮件？），丢给它试试。**底层模型在变聪明，你不需要追着 Astra 跑，你手里的工具会自己变好。**

模型会一代代出，价格会一轮轮降。对普通人来说，这从来不是"押注谁赢"的游戏——**你只需要学会怎么把活儿交代出去，剩下的交给工具。**
