# 第47期 | 我用 AI 搭了条"写稿—排版—发布"流水线（自曝后厨）

> 大家好，我是小智。
>
> 常有读者问："你更新这么勤，是不是有个团队？"
>
> 没有。就我一个人，加一条我自己搭的流水线。
>
> 今天不聊概念，直接开后厨——**从"今天写啥"到"推送出去"，中间到底哪些环节已经交给 AI，哪些我死也不放手。**

📌 本文看点：
- 一条内容流水线的 6 个工位，逐个交代
- 已经自动化的 4 件事，和绝不外包的 3 件事
- 排版这件事，我为什么做成"主题模板"而不是每次重来
- 一张可直接抄走的"开工清单"

---

## 一、先说清楚：流水线不等于"AI 替我写"

很多人一听"用 AI 写稿"，脑子里浮现的是：输入标题 → 出一篇稿 → 发出去。

**真这么干，号早就没了。**

我这条流水线的逻辑恰好相反：**AI 负责"确定性高的重复劳动"，我负责"必须有人负责的判断"。**

打个比方：我开的是个小饭馆。AI 是切配工、洗菜工、摆盘工；**我是那个决定今天卖什么、尝一口咸淡、最后敢不敢端上桌的人。**

---

## 二、六个工位，逐个交底

**① 选题（人，100%）**
写什么，永远是我定。来源有三：读者后台提问、当周热点、规划表里排好的栏目。**这一工位一旦外包，账号就没有人格了。**

**② 素材（AI 搜 + 人核）**
让 AI 去查资料、列事实清单、找对立观点。但它给的每个数字、每条新闻，我都会**自己点开原始出处看一眼**——这是第 48 期要聊的"幻觉"问题，这里先埋一句：**AI 会编，而且是理直气壮地编。**

**③ 起草（AI 出初稿）**
我把结构和口吻交代清楚（比如"以第一人称小智的口吻，用生活化比喻，别写术语"），让它出第一版。**初稿我只当它是"素材草稿"，从来不当成品。**

**④ 把关（人，重灾区）**
这一步最花时间，也最不能省。我做三件事：
- **砍废话**：删掉所有"总的来说""值得注意的是"这类车轱辘话；
- **加自己**：往里塞只有我能写的东西——翻车经历、具体数字、我的立场；
- **查事实**：数字、日期、产品名，逐个回原文核。

**⑤ 排版（模板 + 主题库，半自动）**
这是我这两年最得意的一件事：我把排版做成了一套**主题组件库**——封面卡、章节编号标题、关键词下划线、提示卡、代码块、结尾签名，全是现成组件，还带不同配色主题。

流程变成：Markdown 写完 → 选主题 → 一键生成排版 HTML → 跑校验脚本 → 预览。**同一篇文章换三套皮肤，五分钟的事。**

**⑥ 预览发布（人点最后一下）**
排版完一定在手机预览里从头滚到尾，看有没有断行、错位、图片变形。**发布按钮，永远是人点的。**

---

## 三、已经自动化的四件事

1. **章节编号与结构**：一级标题自动带编号和导语，不用手动敲"一、二、三"；
2. **关键词下划线**：正文里需要强调的词，按规则自动套高亮样式；
3. **配图提示词**：每期文末那几条 AI 绘图提示词，是按当期主题配色自动写的，画风天然统一；
4. **HTML 校验**：有没有微信不支持的标签、有没有漏掉的 `span leaf` 占位，脚本一次性扫出来。

> 这四件事的共同点：**规则固定、重复枯燥、做错了只是难看。** 这种活，就该交给机器。

---

## 四、打死也不交给 AI 的三件事

1. **选题判断**——写什么，是账号的灵魂；
2. **事实核查**——AI 会编造，而且给得像真的。**数字、日期、人名、引用，一律回原文核；**
3. **观点立场**——AI 只会给"最大公约数"，而读者关注你，恰恰是想看你的"偏心"。

> 这三件事的共同点：**做错了会出事，或者会丢人。** 这种活，就该人扛。

---

## 五、一张可以直接抄走的开工清单

```
[ ] 1. 定选题：这条是"读者问的 / 热点 / 规划里的"？一句话说清写给谁看
[ ] 2. 定立场：这篇我到底想说什么？用一句话写下来，全文不许跑偏
[ ] 3. 收素材：让 AI 查，但每个关键事实自己点开原文核一遍
[ ] 4. 出初稿：给 AI 结构 + 口吻 + 禁用词（如"不要写术语、不要车轱辘话"）
[ ] 5. 人工改写：砍废话 → 加自己的经历 → 定语气
[ ] 6. 排版：选主题 → 生成 HTML → 跑校验脚本
[ ] 7. 预览：手机滚一遍，看断行 / 图片 / 代码块
[ ] 8. 发布：标题再读三遍，然后点发送
```

## 六、小智说两句

搭完这条流水线，我最大的感受不是"省时间",而是——

**它把我从重复劳动里捞出来了，让我能把力气花在真正值钱的地方。**

以前我 80% 的时间在做切配、洗菜、摆盘；现在这些交出去了，我 80% 的时间在想"今天到底该说什么"。

> 一句话总结：**AI 不应替你写，它该替你"重复"。把你从流水线上捞出来，你才终于有空当个人。**

如果你也在做内容，建议从最小的一步开始试：**先把排版模板化。** 这一步投入两小时，往后每期都省半小时，是整条流水线里最划算的一块。

你的工作流里，最想甩出去的是哪一环？评论区说说，我挑几个在下期做拆解。

周三（09-23）聊个很重要的问题：**AI 为什么会一本正经地胡说八道？** 也就是我前面埋的"幻觉"。
