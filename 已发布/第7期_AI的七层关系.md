## 一、先看全景图，再分层看

咱们平时用AI聊天，看起来就是"我说一句、它答一句"，特别简单。

但其实，在那句简单的"一问一答"背后，AI悄悄经过了**七层不同的处理**——就像你点一个外卖，从你下单到骑手送到家门口，中间要经过商家、骑手APP、调度、定位、电瓶车……很多环节一样。

这张图把AI的工作机制按从下到上的顺序，画成了一座金字塔：

> **最底层是"原材料"，越往上越"聪明"，最顶层是"真本事"。**

七层分别是（从下到上）：

| 层级 | 名字 | 一句话 |
|------|------|--------|
| 第1层 | **Token** | AI理解文字的"最小单位" |
| 第2层 | **提示词（Prompt）** | 你告诉AI"要做什么" |
| 第3层 | **上下文** | AI用来参考的"背景信息" |
| 第4层 | **Agent（智能体）** | AI里那个"自主干活的管家" |
| 第5层 | **Harness** | 约束管家行为的"家规" |
| 第6层 | **MCP** | 管家外接各类资源的"联络中枢" |
| 第7层 | **Skills** | 管家能调用的"技能库" |

## 二、用"你请管家"的故事讲一遍

我用大家最容易理解的角色——**管家**，把这七层串起来讲一遍：

### 想象：你雇了一个万能管家（AI）

有一天，你跟管家说：**"小智管家，帮我查一下后天去北京的机票，挑个下午出发的、最便宜的。"**

这句话说出来之后，管家就开始干活了。它是怎么一步步完成这件事的？正好对应了这七层：

#### 第1层：Token——把管家能听懂的"字"拆出来

管家听到的是中文，但你必须先把这句中文**拆成它能听懂的最小单位**。

就像你家的扫地机器人不认识"地板"两个字，但认识"地""板"两个图标一样——AI也不认识"机票"这个词，但认识"机"和"票"这两个"小块"。

这些"小块"就叫**Token**——AI理解语言的最小单位。

（这是最底层，没有它，后面一切都不成立。）

#### 第2层：提示词——你给管家下的"任务书"

你说的那句话，管家听懂了之后，会总结成一份"任务书"：

> **任务：查后天去北京的机票**
> **条件：下午出发、最便宜**

这份"任务书"就叫**提示词（Prompt）**。提示词写得好不好，决定了管家能不能办成事。

#### 第3层：上下文——管家随手翻的"备忘录"

管家要办这件事，需要知道一些背景：
- 你平时坐飞机喜欢坐哪个位置
- 你去北京通常去首都机场还是大兴机场
- 你这次出差是公费还是自费

这些背景信息，管家都记在一个"备忘录"里——这就是**上下文**。

管家不是"现想现做"，而是**先翻翻备忘录，再结合新任务综合判断**。

#### 第4层：Agent——那位"自主干活的管家"本体

经过前面几层准备，**Agent（智能体）终于登场了**。

它是管家本人——不是只会说"我能帮你查"的AI，而是**真的能动手查、真的能比较、真的能下单**的智能体。

Agent有三大特点：
- **自主决策**：它自己决定先查哪个网站、用什么条件筛选
- **拆解任务**：把"查机票"这个大任务拆成"查航班、比价格、看时间"三个小任务
- **持续推进**：做完一步再走下一步，不达目标不罢休

#### 第5层：Harness——管家的"家规"

管家能自己决策，但不能为所欲为。它得按照你（或者开发者）定下的**家规**来办差。

这就是**Harness**——个中文翻译过来叫"驾驭框架"。它管的事是：
- **权限边界**：管家能不能删你电脑上的文件？能不能调用你的银行账号？
- **行为规范**：管家说话必须客气，不能乱承诺；办错事必须主动说明
- **安全护栏**：遇到敏感请求（"帮我黑掉一个网站"），管家必须拒绝

**没有Harness，再聪明的Agent也可能闯祸。** 它是"管家头顶的紧箍咒"，也是"让你放心把钥匙交给它的保险绳"。

#### 第6层：MCP——管家的"联络中枢"

管家要办"查机票"这件事，自己搞不定——它得**调用外部资源**：
- 调用航班查询API（接口）
- 调取价格对比数据库
- 调用支付接口下单

怎么调？管家自己不可能啥都会。它得通过一个**统一的联络中枢**——这就是**MCP（Model Context Protocol，模型上下文协议）**。

你可以把MCP理解为**管家桌上的那部"万能联络电话"**。它不需要知道每个航空公司怎么联系，只需要拨号给MCP，MCP自动帮他接上正确的服务。

#### 第7层：Skills——管家的"技能库"

管家手里还装着一堆**可复用的技能**——**Skills**。

比如：
- 搜索技能：上网搜资料
- 翻译技能：把中文翻成英文
- 编程技能：写代码
- 写作技能：写邮件、写报告

Agent接到任务后，会**按需调用**这些技能，就像你打开工具箱，挑出顺手的工具。

Skills是可以不断累积的——管家每学会一项新技能，工具箱就多一件工具。下次遇到类似问题，它就能直接调用，不用从头学。

## 三、一图+一表，整体串一遍

如果用一句话把七层串起来：

> **你说出提示词，交给Agent大管家；所有沟通内容拆成Token记录，全部存入上下文备忘录；Harness家规全程约束管家行为，不乱干活；管家通过MCP联络中枢，外接各类资源；再调用自身的Skills技能，一步步自主完成你交代的所有任务。**

再用一张表，把每层的作用、关键词、对应比喻列清楚：

| 层级 | 关键词 | 比喻 | 在做什么 |
|------|--------|------|----------|
| 1. Token | 拆字 | 食材切块 | 把字拆成模型认识的小块 |
| 2. 提示词 | 任务书 | 你的订单 | 告诉模型"要做什么" |
| 3. 上下文 | 备忘录 | 冰箱里现有的食材 | 提供相关的背景信息 |
| 4. Agent | 管家本人 | 大厨本人 | 自主决策、自主执行 |
| 5. Harness | 家规 | 厨房操作规范 | 约束管家的行为 |
| 6. MCP | 联络中枢 | 外卖平台 | 对接外部资源 |
| 7. Skills | 技能库 | 工具箱 | 调用各种现成的本事 |

## 四、为什么这七层重要？它跟咱普通人有啥关系？

你可能会想："这些底层的东西，我用AI的时候根本接触不到啊，了解它有啥用？"

有用的，而且**有大用**：

### 用法一：知道"AI为什么答得不好"

以后AI答得不好，你不用干着急了。可以一层层排查：
- 是提示词（第二层）写得不清楚？→ 重写问题
- 是上下文（第三层）信息不够？→ 补充背景
- 是AI本身的技能（第七层）还差点意思？→ 换更高级的模型

### 用法二：知道"AI到底能干啥"

看了这七层你就明白：现代AI已经不只是"聊天机器人"了，而是一个**有家规、有技能、有外部资源、还能自主干活的智能体**。这种AI能帮你做的事，远不止"聊天解闷"。

### 用法三：知道"AI会不会闯祸"

Harness和MCP这两层，明确告诉你：**现代AI是有安全机制的，不是为所欲为的**。它会按照"家规"行事，会通过"正规渠道"获取资源。这就让你更放心地把一些事交给它。
